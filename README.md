# 🚀 777Phisher — Security Awareness Lab

**Created by Hackistaan Cybersecurity**

777Phisher is a cybersecurity learning project intended for authorized security research, phishing-awareness demonstrations, and isolated lab experiments.

## 👨‍💻 About Hackistaan

Hackistaan shares educational content about cybersecurity, ethical hacking, networking, Linux, and security awareness.

- **Instagram:** [@Hackistaan7](https://www.instagram.com/hackistaan7/)
- **YouTube:** [HACKISTAAN](https://www.youtube.com/@hackistaan)

## 🎯 Project Objectives

- Understand phishing techniques from a defensive security perspective.
- Learn how to recognize suspicious URLs and impersonation attempts.
- Practice security awareness in a controlled lab environment.
- Understand the importance of protecting credentials and personal information.
- Explore safe security testing and incident-response practices.

## 🛠️ Requirements

- A Linux environment or isolated virtual machine.
- Basic knowledge of Linux terminal commands.
- Git installed.
- Permission to conduct any testing in the selected environment.

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/Elex777/777Phisher.git
cd 777Phisher
```

Review the project files before executing any script:

```bash
ls -la
less README.md
```

**Security note:** Review shell scripts and their network activity before running them. Do not run untrusted scripts with root privileges.

## 🔐 Safe Testing Guidelines

- Use only systems and accounts you own or have explicit permission to test.
- Use fictional credentials and test data.
- Never collect, store, or share real users' passwords or authentication tokens.
- Do not impersonate real services to deceive users.
- Keep demonstrations within an isolated lab environment.
- Stop testing if it affects systems or people outside the authorized scope.
